Contact Form

Contact form setup is simple. In contact.php in the scripts folder, add your email address to the to variable.

<?php
if ($_SERVER['REQUEST_METHOD'] == 'POST') {
	if(!empty($_POST['contact_name']) && !empty($_POST['contact_email']) && !empty($_POST['contact_message'])) {
		$to = 'your-email-address@domain.com'; // Replace with your email.
		$body = "Name: {$_POST['contact_name']}\n\nEmail: {$_POST['contact_email']}\n\nPhone: {$_POST['contact_phone']}\n\nMessage: {$_POST['contact_message']}";
		mail($to, "Contact Form Submission: {$_POST['contact_subject']}", $body, "From: {$_POST['contact_email']}");
	}
}
?>

Feel free to format the email any way you wish (requires some php knowledge).

MailChimp Form

In MailChimp, go to your lists embedded forms. Replace the following x values with the values from your forms action url.

<form action="https://xxxxx.xxx.list-manage.com/subscribe/post-json?u=xxxxx&id=xxxxx&c=?" method="get" target="_blank" id="mc-embedded-subscribe-form" class="newsletter-form">
	<input type="email" id="mce-EMAIL" name="EMAIL" placeholder="Your Email" />
	<input type="submit" id="mc-embedded-subscribe" name="subscribe" value="Go" class="button dark" />
</form>
